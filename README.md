# Трекер расходов

Веб-приложение для учёта личных расходов с аналитикой по дням и неделям. Проект разработан в рамках обучения на направлении «Информационная безопасность» ДГУ.

## Стек технологий
- **Python 3** — основной язык
- **Flask** — веб-фреймворк
- **SQLite** — база данных
- **HTML/CSS** — фронтенд

## Функционал
- Добавление расходов с категорией и датой
- Просмотр расходов за день и неделю
- Подсчёт дневных и недельных итогов
- Установка и контроль бюджета
- Группировка расходов по датам
